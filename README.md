# vims-acp

The [VIMS](https://vims.com) agent for editors that speak the [Agent Client Protocol](https://agentclientprotocol.com) — Zed, JetBrains AI Assistant and others.

This repository holds **releases only**: prebuilt `vims-acp` binaries for macOS, Linux and Windows, published from VIMS's release pipeline, and the ACP registry entry (`agent.json`, `icon.svg`) attached to each release.

`vims-acp` answers through the VIMS app on the same computer — its models, knowledge base, memories, apps and agents. Get VIMS at https://vims.com/download; signing in ("Connect to VIMS") opens it, or the download page if it isn't installed.

Each archive's SHA-256 is in the release's `SHA256SUMS`.
